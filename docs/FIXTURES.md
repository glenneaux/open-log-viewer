## Existing private regression sample

The supplied Haltech recording has 642 recorded channels and 45,670 binary samples. The matching NSP CSV has 45,669 rows. All shared timestamps, channel names, unit types and 29,319,498 values match. The decoder preserves the extra final binary sample.

Set `HALTECH_TEST_LOG` and `HALTECH_TEST_CSV` to the corresponding local files, then run `pnpm test`. `pnpm test:browser` uses `HALTECH_TEST_LOG` to exercise the full import and plotting path. Without these variables, private-fixture tests are explicitly skipped.
